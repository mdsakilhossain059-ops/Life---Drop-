# Life Drop (MVP)

## Replit-এ চালানোর নিয়ম
1. Replit-এ Python project তৈরি করুন।
2. ZIP ফাইলটি extract করে সব ফাইল project-এ upload করুন।
3. Shell-এ `pip install -r requirements.txt` চালান।
4. Run command দিন: `python app.py`
5. Replit-এর web preview থেকে অ্যাপ দেখুন।

## গুরুত্বপূর্ণ
এটি পরীক্ষামূলক MVP। বাস্তবে চালুর আগে HTTPS, production database, OTP/ফোন যাচাই, abuse reporting, admin moderation, privacy policy, backup এবং নিরাপত্তা পরীক্ষা যোগ করতে হবে। ডোনার বা রক্তের অনুরোধ যাচাই ছাড়া জরুরি চিকিৎসার বিকল্প হিসেবে ব্যবহার করবেন না।
